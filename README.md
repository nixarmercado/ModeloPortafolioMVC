\# ModeloPortafolioMVC



¡Bienvenido a mi proyecto de Portafolio basado en la arquitectura \*\*Modelo-Vista-Controlador (MVC)\*\*! Este repositorio sirve como plantilla y demostración de buenas prácticas de desarrollo de software.



\## Características

\*   \*\*Arquitectura Limpia:\*\* Separación estricta de responsabilidades (MVC).

\*   \*\*Diseño Responsivo:\*\* Interfaz adaptada a dispositivos móviles y escritorio.

\*   \*\*Código Escalable:\*\* Estructura modular lista para añadir nuevas secciones.



\## Estructura del Proyecto

El proyecto está organizado bajo el patrón estructural clásico:

\*   `/Models`: Gestión de datos, lógica de negocio y conexiones a bases de datos.

\*   `/Views`: Interfaces de usuario, plantillas HTML, CSS y layouts.

\*   `/Controllers`: Intermediarios que capturan las peticiones del usuario y coordinan los Modelos y Vistas.



\## Tecnologías Utilizadas

\*   \*\*Frontend:\*\* HTML5, CSS3, JavaScript
